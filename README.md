# LS Corretora de Seguros — Projeto de Portfólio

Site institucional fictício desenvolvido como projeto de portfólio para demonstrar habilidades em desenvolvimento front-end.

> **⚠️ Este projeto é disponibilizado exclusivamente para visualização e avaliação. Reprodução não autorizada é proibida. Veja a [LICENSE](https://github.com/luccas-souza7/corretora-de-seguros/blob/main/LICENSE).**

---

## 🎯 Objetivo do Projeto

Simular o desenvolvimento de um site profissional para uma corretora de seguros, cobrindo desde a identidade visual até a experiência do usuário, como seria entregue a um cliente real.

---

## ✨ O que foi desenvolvido

- Layout responsivo e moderno com foco em conversão
- Formulário de cotação com integração ao WhatsApp
- Carrossel de depoimentos de clientes
- Seção de FAQ interativa
- Animações suaves baseadas em scroll (Intersection Observer)
- Páginas: Principal, Sobre e Política de Privacidade

---

## 🛠️ Tecnologias utilizadas

| Camada | Tecnologia |
|--------|-----------|
| Estrutura | HTML5 semântico |
| Estilo | CSS3 com variáveis customizadas |
| Comportamento | JavaScript vanilla |
| Ícones | Font Awesome |
| Tipografia | Google Fonts (Sora + DM Sans) |
| Carrosséis | Splide.js |

Zero frameworks. Zero dependências de build.
